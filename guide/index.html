学习路线 ​

微前端不是一个库，而是一组把多个独立应用组装成一个产品的工程方法。学习它最容易踩的坑，是一上来就抄配置：能跑，但不知道为什么，出问题也定位不了。

本教程按“认知 → 原理 → 实战 → 工程 → 精通”组织，每一层都能独立停下，也都为下一层服务。

五个阶段 ​

阶段一：建立认知 ​

先回答三个问题：

  1. 我们的痛点到底是“团队协作”还是“技术栈统一”？
  2. 微前端能解决什么，不能解决什么？
  3. 现在做，收益是否大于复杂度成本？

对应章节：微前端是什么、何时用，何时不用、技术演进。

阶段二：理解原理 ​

所有方案都在处理五件事：

关注点典型问题
加载子应用的 HTML、JS、CSS 怎么被取回并执行？
隔离全局变量、定时器、事件、样式怎么不互相污染？
路由主应用与子应用谁管 URL？刷新后怎么恢复？
通信props、全局状态、事件总线怎么选？
治理版本、灰度、监控、回滚怎么落地？

对应章节：原理总览。

阶段三：动手实战 ​

七套示例按“隔离强度”和“改造成本”排序，建议至少完整跑通三套：

  1. iframe：理解隔离的基线。
  2. qiankun：国内最常见的生产方案。
  3. Module Federation：构建时集成的另一条路。

其余方案按团队技术栈取舍阅读。

阶段四：工程落地 ​

能跑 demo 和能上线之间，差着部署、监控、性能与治理。对应章节：工程化进阶。

阶段五：直达精通 ​

读源码、做迁移、查故障、写选型报告。对应章节：直达精通。

建议节奏 ​

周次任务产出
第 1 周读完 guide 与 principles，跑通 iframe能讲清隔离与通信的基本取舍
第 2 周跑通 qiankun 与 micro-app能解释 HTML Entry 与沙箱差异
第 3 周跑通 Module Federation，读 single-spa 源码能对比“运行时集成”与“构建时集成”
第 4 周做一次小范围迁移方案选型报告 + 迁移与回滚计划

前置知识 ​

  • Vue 3 或 React 18 的基础开发能力。
  • 了解 Vite 的基本配置与构建产物。
  • 知道浏览器同源策略、postMessage、Shadow DOM 的大致概念。
  • 能使用 Git 与 CI（本教程用 GitHub Actions 演示）。

配套示例怎么用 ​

每套示例都包含一个主应用和一到两个子应用，端口固定。启动方式见各方案页的“运行”小节。

推荐练习方式：

  1. 先按文档跑通。
  2. 改一个变量，观察日志面板的变化。
  3. 故意制造一次样式冲突或全局变量污染。
  4. 用原理章节解释你看到的现象。

阅读约定 ​

  • 代码块中的路径均相对于仓库根目录。
  • “坑点”小节只写真实会遇到的问题，不写理论风险。
  • 每篇方案末尾都有“验证清单”，全部通过才算真正跑通。

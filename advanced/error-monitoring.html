错误边界与监控 ​

微前端里最糟糕的体验是：一个子应用报错，整个页面白屏。最糟糕的排查体验是：报错堆栈指向压缩后的 index-3f2a.js。

三层错误防线 ​

text
1. 子应用内部：组件级错误边界
2. 主应用容器：加载失败 / 挂载失败兜底
3. 全局：window.onerror / unhandledrejection / 资源错误

Vue：

app.config.errorHandler = (error, instance, info) => {

React：

tsx
class ErrorBoundary extends React.Component {
  state = { hasError: false };

  static getDerivedStateFromError() {
    return { hasError: true };
  }

  componentDidCatch(error: Error, info: React.ErrorInfo) {
    report("react-error", { error, info });
  }

  render() {
    return this.state.hasError ? <Fallback /> : this.props.children;
  }
}

第三层：全局捕获 ​

ts
window.addEventListener("error", (event) => {
  // 资源加载失败不会冒泡，需要捕获阶段
  report("resource-error", {
    target: event.target,
    message: event.message,
  });
}, true);

window.addEventListener("unhandledrejection", (event) => {
  report("unhandled-rejection", { reason: event.reason });
});

注意：error 事件对资源错误不冒泡，必须用捕获阶段，或单独监听：

ts
document.addEventListener(
  "error",
  (event) => {
    const target = event.target as HTMLElement;
    if (target?.tagName === "SCRIPT" || target?.tagName === "LINK") {
      report("resource-error", { src: target.getAttribute("src") });
    }
  },
  true,
);

上报字段设计 ​

建议至少包含：

ts
interface ReportPayload {
  app: string;          // 子应用名
  version: string;      // 子应用版本
  route: string;        // 当前路由
  traceId: string;      // 链路 ID
  type: string;         // 错误类型
  message: string;
  stack?: string;

Source Map ​

生产环境要能还原堆栈：

  • 构建时生成 Source Map。
  • 上传到监控平台，不要把 .map 暴露在公网。
  • 或在网关层限制 .map 访问。

Vite：

ts
build: {
  sourcemap: true,
}

指标与告警 ​

指标说明
子应用加载成功率按应用、版本、地区统计
首屏耗时主应用 + 当前子应用
错误率每千次访问的错误数
API 失败率子应用接口维度
白屏率页面无内容或关键节点缺失
版本分布灰度期间各版本占比

告警阈值建议从真实基线出发，不要拍脑袋设 0。

降级策略 ​

出现故障时，优先级是“可用”而不是“完整”：

  1. 子应用加载失败 → 显示兜底页 + 重试。
  2. 新版本错误率升高 → 自动切回旧版本。
  3. 远程模块不可用 → 隐藏该模块，保留主流程。
  4. iframe 超时 → 提示用户刷新。

降级开关要能通过配置中心实时生效。

排查清单 ​

  • [ ] 子应用错误是否带 app 与 version？
  • [ ] 是否有 traceId 关联主应用与子应用日志？
  • [ ] Source Map 是否已上传？
  • [ ] 资源 404 是否能被捕获？
  • [ ] 加载超时是否有兜底？
  • [ ] 灰度版本错误率是否单独统计？

样式隔离 ​

样式污染是微前端最常见、也最容易被低估的问题。一个子应用写了：

css
button { background: red; }
1

主应用所有按钮都可能变红。更隐蔽的是：

css
body { font-size: 14px; }
@keyframes spin { ... }
:root { --brand: #f00; }
1
2
3

这些全局规则很难靠命名约定彻底避免。

四种隔离手段 ​

1. Shadow DOM ​

浏览器原生封装。Shadow Root 内的样式不会泄漏到外部，外部选择器也无法直接命中内部节点（继承属性除外）。

js
const host = document.querySelector("#order-widget");
const shadow = host.attachShadow({ mode: "open" });
shadow.innerHTML = `
  <style>button { background: teal; }</style>
  <button>订单</button>
`;
1
2
3
4
5
6

特点：

  • 隔离强度最高，接近 iframe。
  • 继承属性（color、font-family）仍会穿透。
  • 事件会冒泡到宿主元素，可用 composed: true 跨边界。
  • 弹窗挂到 document.body 时会跳出 Shadow DOM。

使用者：Web Components、micro-app、wujie（渲染层）。

2. 选择器改写（Scoped CSS） ​

构建或运行时给选择器加前缀：

css
/* 原始 */
.title { color: #333; }

/* 改写后 */
div[data-qiankun="qk-order"] .title { color: #333; }
1
2
3
4
5

qiankun 的 experimentalStyleIsolation 就是运行时改写：

js
start({
  sandbox: {
    experimentalStyleIsolation: true,
  },
});
1
2
3
4
5

特点：

  • 改造成本低，子应用无需改代码。
  • 对 body、html、:root 等全局选择器处理有限。
  • @keyframes、@font-face 需要额外处理。
  • 动态插入的样式可能漏改写。

3. CSS Modules / Scoped ​

构建期把类名哈希化：

css
/* Button.module.css */
.primary { color: #2563eb; }
1
2

编译为 .primary_3f2a1，天然不冲突。

特点：

  • 适合组件级样式。
  • 无法约束第三方库注入的全局样式。
  • 需要子应用改造构建配置。

Vue 的 <style scoped> 也属于这一思路，但只作用于组件模板。

4. 命名空间约定 ​

例如 BEM 前缀：

css
.mf-order__title { ... }
1

特点：

  • 零成本，但完全依赖团队自觉。
  • 无法防御第三方库。

组合策略 ​

生产环境通常不是“只用一种”，而是：

text
Shadow DOM（页面级隔离）
  + CSS Modules（组件级隔离）
    + 命名约定（兜底）
1
2
3

例如 micro-app 用 Shadow DOM 做页面级隔离，子应用内部仍用 scoped 样式。

容易漏掉的污染源 ​

污染源说明处理
body / html改全局字体、背景约定禁止，或运行时移除
:root 变量覆盖主题变量加子应用前缀
@keyframes动画名冲突加前缀或改写到 Shadow DOM
@font-face字体全局注册统一由主应用管理
!important破坏优先级代码评审拦截
动态 <style>运行时插入沙箱拦截或改用 Shadow DOM
弹窗 / Toast挂到 body提供统一的 portal 容器

各方案对照 ​

方案默认样式隔离可选增强
iframe完全隔离无需
Web ComponentsShadow DOM无
single-spa无自行引入 CSS Modules / Shadow DOM
qiankun无（默认）experimentalStyleIsolation、strictStyleIsolation
micro-appShadow DOM可关闭
wujieShadow DOM可配置
Module Federation无组件内 scoped / CSS Modules

验证样式隔离是否有效 ​

在示例项目的“全局样式攻击”按钮里，我们故意注入：

css
button { background: red !important; }
1

观察结果：

  • iframe：子应用不受影响。
  • Web Components / micro-app / wujie：Shadow DOM 内部不受影响。
  • qiankun：开了 experimentalStyleIsolation 后，子应用样式被限定在容器内。
  • single-spa：会被污染。

这个实验比读十篇文章更能建立直觉。

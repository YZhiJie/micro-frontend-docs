延伸阅读 ​

按阅读目的推荐：

  • 想理解隔离原理：先读 qiankun 的沙箱源码（src/sandbox），再读 wujie 的 iframe + proxy 设计文档。
  • 想理解 HTML Entry：读 import-html-entry 的 index.js，重点看 execScripts 与样式提取。
  • 想理解路由劫持：读 single-spa 的 navigation 模块，关注 history.pushState 的改写与 popstate 派发。
  • 想做选型：读各方案 README 中的"限制"章节，比读功能列表更有价值。
  • 想做治理：参考治理与安全中的清单，结合团队实际裁剪。

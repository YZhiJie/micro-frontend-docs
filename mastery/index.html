精通总览 ​

“精通微前端”不是记住七个库的 API，而是具备四种能力：

能力表现章节
读源码能定位加载、沙箱、路由的关键实现源码级剖析
做迁移能把老系统渐进迁移且可回滚迁移路线
查故障能根据现象快速定位根因故障手册
做决策能写出有依据的选型报告选型对比

能力自测 ​

入门 ​

  • 能跑通任意一套示例。
  • 能解释 props 与全局状态的区别。
  • 能说出 iframe 的三个缺点。

熟练 ​

  • 能独立接入一个 qiankun 或 micro-app 子应用。
  • 能定位样式污染与路由 404。
  • 能配置 CORS 与 UMD 构建。
  • 能设计一套通信契约。

精通 ​

  • 能读 single-spa 的 reroute 流程。
  • 能解释 qiankun Proxy 沙箱的 with 包裹。
  • 能设计灰度与回滚方案。
  • 能在故障现场根据日志定位到具体子应用与版本。
  • 能写出包含成本、风险、收益的选型报告。

学习方式 ​

  1. 读源码：不要逐行读，带着问题读。
  2. 做实验：每读一个机制，就在示例里制造一次对应故障。
  3. 写复盘：把排查过程写成文档，形成团队资产。
  4. 做迁移：真实迁移一次，胜过读十篇文章。

推荐顺序 ​
